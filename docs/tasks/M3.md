# Task: M3 (web app)

**Status:** M3a, M3b and M3c are implemented (`apps/web/src/pages`, `src/Layout.tsx`, `src/router.tsx`).
Deviations from the plan below:
- No fixture JSON in `public/data/`: shipping invented numbers with the site would be misleading. The pages read
  `/data/*.json` when M4 publishes it and fall back to the API; Playwright answers every API call from `tests/fixtures.ts`.
- Lighthouse CI moves to M4, where a deployed URL exists. The Home bundle budget is enforced now (`npm run size`).
- Home shows common searches instead of a categories grid: `/api/search` requires `q`, so browsing a category
  without a query needs an API change first (follow-up).
- The price index page shows an empty state until M4 produces `index_monthly`.

Start after M2b is merged (typed GraphQL documents and REST types exist). Read `AGENTS.md`,
`docs/ARCHITECTURE.md` section 5 and `docs/design/README.md` first. Three PRs, in order; stop and report after each.

## M3a — Foundation
1. Move `docs/design/theme.css` to `apps/web/src/styles/theme.css`; self-host Source Sans 3 (latin-ext + cyrillic).
2. Routes (TanStack Router, code-split per route): `/`, `/pretraga?q=&kategorija=`, `/proizvod/$barcode`, `/korpa`,
   `/indeks`, `/kvalitet`, `/o-projektu`, plus a 404. Each route sets `<title>` and a meta description.
3. Layout shell: header (wordmark, search, basket link with count, script toggle), `<main>`, footer with sources and
   the disclaimer. Skip link to main content.
4. i18n is in place (`I18nProvider`, `transliterate`, plurals). Extend it only if a page needs something new.
5. Data layer: `VITE_API_URL`; TanStack Query hooks using the generated types (`useSearch`, `useProduct`,
   `useBasket`, `useCategories`, `useQuality`). Categories and quality read static JSON first
   (`/data/categories.json`, `/data/quality.json`, same shape as the REST responses), API as fallback.
   For M3, commit small fixtures in `apps/web/public/data/`; M4 generates the real files nightly.
6. Basket store: localStorage `{ barcode, qty }[]`, max 50 items, survives reload, no personal data.
7. Test setup: Vitest + Testing Library; Playwright with `@axe-core/playwright`; Lighthouse CI; `size-limit`
   (Home ≤ 105 KB JS gzip, see docs/design/README.md). All wired into CI.
