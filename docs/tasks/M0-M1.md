# Task: M0 (setup) + M1 (ingest)

Read `AGENTS.md` and `docs/ARCHITECTURE.md` first and follow them. Implement M0 and M1, then stop and report.
Open one PR per phase if practical (M0 first), otherwise one PR with clearly separated commits.

## M0 — Setup
1. Create the monorepo layout from `AGENTS.md`.
   - `apps/api`: FastAPI app with `GET /health`.
   - `apps/web`: React 19 + Vite + TypeScript strict + Tailwind + TanStack Router/Query, placeholder home page.
   - `packages/ingest`: Python package with a typer CLI `korpa` exposing `ingest`.
2. `infra/docker-compose.yml` with Postgres 16 + pgvector + pg_trgm. Alembic in `apps/api` with the tables from
   `docs/ARCHITECTURE.md` section 3.
3. `Makefile` targets: `dev`, `test`, `e2e`, `lint`. GitHub Actions CI: ruff, mypy, pytest, eslint, tsc, vitest, build.
4. `.env.example` with the variable names from `AGENTS.md`.

## M1 — Ingest
5. Portal discovery spike: find out how to list the retailers' price-list datasets on the Serbian open data portal
   (data.gov.rs) through its API, how resource URLs look, and whether responses carry ETag / Last-Modified and a
   license. Write findings, with the exact URLs you used, to `docs/data-notes.md`. If the sandbox has no network,
   write the client behind an interface with recorded fixtures and mark the spike as TODO in the PR.
6. CSV reader: detect the delimiter, strip a BOM, require the 15 columns exactly as named in `AGENTS.md`, parse
   `DD-MM-YYYY` dates, convert prices with `.` decimals to integer para, validate the barcode as 13 digits (text).
7. Normalizer + upsert: `retailers`, `retail_formats`, `products` (by barcode), `product_names`, `prices_current`;
   append to `price_changes` only when a price changed; `MESEČNI_PRESEK` rows go to `monthly_snapshots`.
8. One `ingest_runs` row per retailer with totals and errors grouped by type; `korpa ingest --dry-run` prints the
   report without writing.
9. Tests with fixture CSVs, good and broken (see the quality gates in `AGENTS.md`). Aim for meaningful coverage of
   the reader and normalizer.

## Report back
What works, what you verified about the portal (with URLs), what is still unknown, and the exact commands to run
everything locally.
