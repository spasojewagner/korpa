# Task: M5 (AI basket, grounded index notes, MCP server, evaluation)

Read `AGENTS.md`, `docs/ARCHITECTURE.md` and `docs/adr/0002-ai-without-embeddings.md` first.

## Principle
The language model never produces a price, a barcode, a date or a product fact. It turns a sentence into search
queries and quantities, or rewrites numbers it is given. Every number shown comes from the database, and every
model output is validated before use. Without `LLM_API_KEY` the AI features are hidden and the rest works.

## Configuration (names only; values live in Render/GitHub settings)
`LLM_PROVIDER=gemini|groq`, `LLM_API_KEY`, `LLM_MODEL` (an explicit model for that provider).

## A — Basket from a sentence (maintainer)
`POST /api/ai/basket` `{ "sentence": "mleko, hleb i 10 jaja" }` (3–300 chars) →
```jsonc
{
  "as_of": "2026-11-22", "model": "<LLM_MODEL>",
  "items": [
    { "phrase": "10 jaja", "query": "jaja", "qty": 10,
      "candidates": [ /* up to 5 SearchItem rows from /api/search, same shape */ ] }
  ]
}
```
Model output schema: `{ "items": [{ "phrase": str, "query": str (2–60), "qty": int 1–99 }] }`, at most 20 items;
anything else is dropped by validation. Limits: 10 requests/minute per client, 500/day in total (the free tier),
10 s model timeout. Errors are problem+json: 503 when AI is not configured or the model fails, 429 over a limit.
Web: on `/korpa`, "Napiši šta kupuješ" → items with candidates → the user picks and adds; nothing is added silently.

## A2 — Goals and budget — done
A sentence may describe a goal instead of products ("ručak za četvoro do 500 din"). The model may then propose
at most 8 ingredients, each marked `proposed: true`, and returns a stated budget as `budget_rsd`. Candidates, names and
prices still come only from the product search. The web marks proposals with "Predlog" and compares the budget with
the lowest possible total of the chosen products (each at its cheapest format); the per-chain total is in the basket.
The same sentence and model reuse a validated extraction for 24 hours (in memory, at most 500 entries), which saves
the free model quota. Evaluation scores only named products; proposals are suggestions the shopper confirms.

## B — Grounded index notes (maintainer) — done
Nightly, `export_static` sends the model a few facts from `index.json` (the overall index and the three largest rises
and falls since the base month, numbers formatted and rounded exactly as `/indeks` shows them) and asks for at most
three short Serbian sentences, each with the codes of the categories it mentions. `korpa_api.ai.notes` keeps a
sentence only if:
- every number in it appears in the general facts or in the facts of the categories it names;
- its direction words (rast/poskupljenje vs pad/pojeftinjenje) do not contradict those categories;
- it has no cause or prediction words (zbog, usled, očekuje, biće, ...) and no Cyrillic.
Failing sentences are dropped, never repaired. Kept sentences go to `index.json` as
`notes: {model, items}`; the key is absent when AI is off, the model fails, or nothing survives, so the export and
the site work the same without a key. `/indeks` shows them under "Kratak pregled", labelled as automatic text with
the data date. The deploy workflow passes `LLM_API_KEY` and `LLM_MODEL` from GitHub secrets to the export step only.

## C — MCP server — done
Read-only MCP server mounted at `/mcp` on the API (official `mcp` Python SDK, streamable HTTP), tools:
`search_products(query, category?, limit≤20)`, `compare_prices(barcode)`, `cheapest_basket(items[{barcode, qty}] ≤ 50)`.
They call the same repository functions as REST, return the same numbers with `as_of` and list dates, and never
write. Tests with the SDK's client against the ASGI app; README section with a client config example.

## D — Evaluation — done (labelled set from the maintainer)
`docs/ai-eval/phrases.jsonl`: 50 Serbian sentences with expected items (`query_terms`, `qty`, `category`).
`python -m korpa_api.ai.evaluate` runs part A's extraction plus search and reports: item recall and precision,
quantity accuracy, and top-1 / top-5 match (the expected category and every query term in the candidate's name).
Modes: `--recorded` (default, uses committed model responses, runs in CI) and `--live` (needs the key, refreshes
the recordings). Results go to `docs/ai-eval/results.md` with model name and date.

## Done when
Gates green; AI hidden without a key; evaluation published; MCP tools usable from a standard MCP client.
