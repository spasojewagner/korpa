# Demo recording script — 60 seconds

Draft for manual recording; no recording or publication has been made by this document.
Use the deployed design as it stands. Show source dates and keep the pointer slow enough to follow.
Before recording, wake the API with ordinary search, choose available products and prepare the basket.
For the assistant segment, use an already captured genuine result if available; otherwise show the goal input
without submitting it and say that candidates require confirmation. Do not fabricate a result or label old
footage as current. TODO: choose and date the genuine assistant clip before final editing.

| Time | Screen action | Spoken Serbian copy |
|---|---|---|
| 00–10 s | Home → search `mleko`; open a product and point to source dates | „Korpa poredi objavljene cenovnike. Tražim mleko i vidim cene i datume izvora.“ |
| 10–22 s | Add chosen items → `/korpa`; point to the cheapest complete format and a partial row | „Za iste artikle upoređujem kompletnu korpu po formatu. Nepotpune korpe su posebno označene.“ |
| 22–30 s | Scroll to cheapest per item | „Kupovina svakog artikla tamo gde je najjeftiniji može uključiti više formata. Put i dostava nisu uračunati.“ |
| 30–42 s | Assistant: enter `ručak za četvoro do 500 din`; show genuine saved candidates and budget if available | „Mogu da zadam cilj i budžet. Pomoćnik predlaže pretrage; artikle i cene uzima iz podataka, a izbor potvrđujem ja.“ |
| 42–52 s | `/podaci/indeks`: point to provisional label, method and notes if present | „Indeks prati redovne cene od baznog meseca. Tekuća tačka je privremena; kratak pregled se proverava prema brojevima.“ |
| 52–60 s | `/podaci` → quality → `/podaci/api`; finish with footer disclaimer | „U Podacima su izvori, greške i pristup kroz API i MCP. Korpa je nezavisan projekat.“ |

If notes are absent, show the method and say „Pregled može izostati kada nema proverenog teksta.“
Do not announce a cheapest retailer, savings amount or budget success unless visible in that recording.
The six intervals total 60 seconds; trim waiting time through clearly edited cuts, without changing results.
